# 給与計算用電卓

アルバイトの月間給与を素早く見積もるための静的Webアプリです。

## 機能

- 時給、勤務日数、勤務時間、休憩時間から基本給を計算
- 残業割増、深夜割増、交通費、手当、控除、税率目安に対応
- 総支給、手取り見込み、月間勤務時間を即時表示
- スマートフォンとPCの両方で使いやすいレスポンシブ画面

## 使い方

`index.html` をブラウザで開くと利用できます。入力値を変更すると結果が自動で更新されます。

## 注意

表示される金額は目安です。税金や社会保険、端数処理は勤務先や契約条件によって変わります。

## テスト

```bash
node tests/calculator.test.mjs
```
